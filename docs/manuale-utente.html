Usare scrap

Come installare scrap, scaricare file anche molto grandi, copiare un sito intero, scegliere con i filtri cosa scaricare, entrare nei siti con accesso riservato e cavarsela quando qualcosa non va. Alla fine trovi il riferimento completo di tutte le opzioni.

Versione 1.1 Sistema Linux (x86-64 e ARM a 64 bit) Programma un unico file, niente da installare

Sommario

Premi / per cercare. L'indice analitico in fondo elenca opzioni, file e argomenti.

Introduzione

Che cos'è scrap, cosa fa e cosa volutamente non fa.

Che cos'è

scrap è un programma da terminale per scaricare dal web. Unisce in un solo strumento due cose che di solito richiedono due programmi diversi: scaricare un file velocemente, aprendo più collegamenti insieme sullo stesso file, e copiare un sito intero (o una sua parte) seguendo i link da una pagina all'altra. In mezzo ci sono tanti filtri per scegliere esattamente cosa tenere: solo le immagini, solo i PDF sotto una certa dimensione, solo le pagine di un certo sito, e così via. Per questo lo chiamiamo «il coltellino svizzero del download».

È un unico file eseguibile: non ha bisogno di installare altro, nemmeno i certificati di sicurezza per i siti https, che porta con sé.

⇉

Divide un file grande in 4 pezzi (o quanti ne vuoi) scaricati insieme: spesso molto più veloce.

Guida integrata

Cosa non fa

  • Non esegue JavaScript. scrap legge le pagine così come arrivano dal server: i siti che costruiscono il contenuto nel browser con JavaScript (molti siti moderni) si copiano solo in parte.
  • Non aggira protezioni: captcha, attese, limiti. Per i siti di file hosting con account esiste il progetto gemello hoster.
  • Di norma rispetta robots.txt, il file con cui un sito chiede ai programmi automatici di non visitare certe parti (vedi Le regole del sito).
Uso previsto

Scaricare contenuti che si è autorizzati a scaricare, con un ritmo rispettoso dei server. Quando copi un sito non tuo, tieni basso il numero di download contemporanei (-j) e, se il sito è piccolo, limita la banda (--rate).

Come funziona, in breve

flowchart LR
  A["uno o più indirizzi<br/>(o una lista con -i)"] --> B{"-r o -m?"}
  B -->|"no"| C["scarica ogni file<br/>a più connessioni"]
  B -->|"sì"| D["legge le pagine<br/>e segue i link"]
  D --> E["filtri: cosa tenere"]
  E --> C
  C --> F["file sul disco<br/>(ripresa con -c)"]

Senza opzioni particolari scrap scarica gli indirizzi che gli dai. Con -r (o -m) apre le pagine web, ne raccoglie i link e continua di pagina in pagina, tenendo solo quello che passa i filtri.

Installazione

Tre strade: il programma pronto nel repository, il programma pronto dalle release, oppure costruirlo dal codice sorgente.

Il programma pronto, con git clone

Il repository contiene già il programma compilato, il file scrap (per PC e tablet Linux con processore Intel o AMD). Basta clonarlo:

$ git clone https://github.com/nic-fio/SCRAPER.git
$ cd SCRAPER
$ ./scrap --help

Non serve installare altro.

Solo il programma, dalle release

Nella pagina delle release su GitHub ci sono due file:

FilePer
scrap-linux-amd64PC e tablet Linux con processore Intel o AMD (la maggior parte).
scrap-linux-arm64Raspberry Pi 4 o 5 e altri ARM a 64 bit.

Se non sai quale ti serve, il comando uname -m te lo dice: x86_64 vuol dire amd64, aarch64 vuol dire arm64. Per altri sistemi (Mac, Windows, ARM a 32 bit) si può costruire il programma dal sorgente: vedi il manuale tecnico. Scaricato il file:

$ mv ~/Scaricati/scrap-linux-amd64 scrap
$ chmod +x scrap
$ ./scrap --help

La pagina della release contiene anche SHA256SUMS, per controllare che il file sia arrivato integro: sha256sum -c SHA256SUMS --ignore-missing.

Usarlo da qualunque cartella

Per scrivere solo scrap invece di ./scrap, copialo in una cartella dei programmi (chiede la password):

$ sudo install -m 0755 scrap /usr/local/bin/scrap
$ scrap --help

Negli esempi di questo manuale il programma si chiama semplicemente scrap.

Dal codice sorgente

Serve una macchina Debian o Ubuntu con connessione a Internet. Lo script tools/setup-dev.sh controlla e installa quello che manca (il compilatore Go e pochi altri pacchetti; chiede la password per sudo):

$ git clone https://github.com/nic-fio/SCRAPER.git
$ cd SCRAPER
$ tools/setup-dev.sh --install
$ make
$ make test

make ricostruisce il programma scrap dal codice; make test esegue tutti i controlli automatici. Serve solo se vuoi modificare scrap.

Primi passi

Il primo download, cosa si vede sullo schermo e dove finiscono i file.

Scaricare un file

$ scrap https://esempio.it/immagini/debian.iso

Il file viene salvato nella cartella da cui lanci il comando, con il suo nome (debian.iso). Mentre scarica, scrap mostra una riga per ogni file in corso:

 ⬇ debian.iso          ▕██████████▎░░░░░░▏  64%  503M/781M  17.0M/s  16s
    └ seg ▰▰▱▱ ▰▰▰▱ ▰▰▰▰ ▰▰▱▱  (4 connessioni)
────────────────────────────────────────────────────────────────────────
 1 attivi · 0 fatti · 503M · 17.0M/s

Nella prima riga: nome, barra, percentuale, quanto è arrivato sul totale, velocità e tempo che manca. La riga └ seg mostra i pezzi del file che arrivano in parallelo, uno per connessione. In fondo, il conteggio dei file attivi e finiti, il totale scaricato e la velocità complessiva. Quando un file finisce, al suo posto compare una riga con ✓; alla fine, il riepilogo:

 ✓ debian.iso  781M  16.4M/s
✓ 1 file · 781M in 48s · media 16.4M/s

Se qualcosa non è andato, il riepilogo inizia con ✗ e dice quanti indirizzi sono falliti; il motivo è scritto sopra, in una riga che inizia con scrap:.

Dove salva e con che nome

  • Cartella: con -d scegli dove salvare (la cartella viene creata se non c'è): scrap -d ~/iso https://…/debian.iso.
  • Nome: con -o scegli il nome del file: scrap -o debian-12.iso https://…/download?id=42. Vale per un solo indirizzo: con più indirizzi, o insieme a -r/-m, scrap si ferma e ti chiede di usare -d.
  • Nomi strani: le lettere accentate, gli spazi e i simboli nel nome vengono sostituiti con _; se l'indirizzo ha una parte dopo il ?, finisce nel nome dopo una @ (download@id_42). Con -o scegli tu un nome pulito.

Mentre un file è in corso si chiama NOME.part; prende il nome definitivo solo quando è completo.

Scaricare una lista di indirizzi

Metti gli indirizzi in un file di testo, uno per riga. Le righe vuote e quelle che iniziano con # vengono saltate:

# ISO da scaricare stanotte
https://esempio.it/debian.iso
https://esempio.it/ubuntu.iso

$ scrap -i lista.txt -d ~/iso

Puoi anche scrivere più indirizzi direttamente nel comando, uno dopo l'altro, e combinarli con -i.

Scaricare file

Come si comporta scrap durante il download e come regolarlo.

Connessioni per file

Di norma scrap divide ogni file in 4 pezzi scaricati insieme, ognuno con la sua connessione. Molti server limitano la velocità di ogni singola connessione: con più pezzi insieme si arriva più in fretta. -s 8 usa 8 connessioni, -s 1 una sola.

La divisione avviene solo se il server accetta i download «a pezzi» e se il file è di almeno 1 MB (--min-split cambia la soglia). Altrimenti scrap scarica il file con una sola connessione, senza che tu debba fare niente.

Quanti file insieme

Di norma scrap lavora su 4 file alla volta (-j cambia il numero). Con una lista lunga, -j 8 va più veloce se la linea regge; -j 1 scarica un file per volta. Quando copi un sito, lo stesso numero vale per le pagine lette contemporaneamente.

Interruzioni e ripresa

Se la connessione cade, scrap riprova da solo fino a 5 volte (--retries) e riparte dal punto a cui era arrivato. Tra un tentativo e l'altro aspetta 2 secondi, poi 4, poi 8… fino a un massimo di un minuto (--retry-wait sceglie l'attesa iniziale); se il server dice quanto aspettare, scrap aspetta quel tempo. Non riprova invece quando il server risponde con un rifiuto definitivo, per esempio «file non trovato» (404) o «accesso negato» (403): ritentare non cambierebbe niente.

Se interrompi tu il programma (Ctrl+C), rilancia lo stesso comando aggiungendo -c:

$ scrap -c -i lista.txt -d ~/iso

I file rimasti a metà (.part) ripartono da dove erano arrivati. I file già completi vengono sempre saltati, con o senza -c: il riepilogo li conta come già presenti.

Da sapere

Senza -c un file rimasto a metà ricomincia da zero. Dopo uno spegnimento improvviso (batteria scarica, non Ctrl+C) è più prudente cancellare il .part di quel file e riscaricarlo: gli ultimi dati scritti prima dello spegnimento potrebbero non essere arrivati sul disco.

Limitare la banda

--rate fissa un limite complessivo, valido per tutti i download insieme:

$ scrap --rate 2M -i lista.txt

Le dimensioni in scrap si scrivono con un numero e un'unità: k (kilobyte), M (megabyte), G (gigabyte), T, anche minuscole e con i decimali (1.5M); va bene anche la forma 10MB. Per --rate sono byte al secondo: 2M è circa 2 megabyte al secondo, cioè circa 16 megabit. 0, il valore normale, vuol dire nessun limite.

Reti lente o instabili

--timeout (60 secondi) è il tempo massimo di attesa quando il server non risponde: per collegarsi, per la prima risposta e, durante un download, senza ricevere nemmeno un byte. Non limita la durata di un download: un file di molti gigabyte può durare ore. Se il server si blocca a metà, dopo --timeout secondi scrap interrompe e riprova dal punto giusto. Su una rete molto lenta si può alzare, per esempio --timeout 120 --retries 10.

Copiare un sito

Seguire i link da una pagina all'altra e ricostruire il sito sul disco.

Seguire i link

$ scrap -r https://esempio.it/manuali/

Con -r scrap apre la pagina, raccoglie tutti i suoi link (collegamenti, immagini, fogli di stile, script, video…) e li scarica; per ogni pagina web trovata ripete lo stesso lavoro. Si ferma dopo 5 passaggi di link dalla pagina iniziale: la profondità, che si cambia con -l (-l 2: la pagina iniziale, le pagine a cui porta, e quelle a cui portano queste). -l inf toglie il limite.

Copia completa

$ scrap -m --convert-links https://esempio.it/

-m è la copia completa di un sito: come -r, ma senza limite di profondità. Con --convert-links, alla fine scrap riscrive i link delle pagine salvate perché puntino ai file sul tuo disco: apri esempio.it/index.html nel browser e navighi anche senza rete.

Come vengono salvati i file

Con -r e -m scrap ricostruisce le cartelle del sito, dentro una cartella con il nome del sito:

esempio.it/
├── index.html              ← la pagina https://esempio.it/
├── chi-siamo.html
├── manuali/
│   ├── index.html          ← la pagina https://esempio.it/manuali/
│   └── guida.pdf
└── img/
    └── logo.png

Un indirizzo che finisce con / diventa index.html; una pagina web senza estensione riceve .html in fondo. Senza -r/-m, invece, ogni file finisce direttamente nella cartella di destinazione, con il solo nome.

Restare dentro il sito

  • Altri siti: di norma scrap segue solo i link verso il sito di partenza (e i suoi sottodomini: partendo da esempio.it va bene anche www.esempio.it). --span-hosts toglie questo limite: usalo sempre insieme a un filtro, altrimenti rischi di scaricare mezzo web.
  • Siti scelti: --domains esempio.it,cdn.esempio.net segue solo questi siti; --exclude-domains pubblicita.com li esclude.
  • Solo sotto una cartella: --no-parent non risale sopra la cartella di partenza. Partendo da https://esempio.it/manuali/ scarica /manuali/… ma non /blog/.

Le pagine complete di immagini e stili

Una pagina web da sola non basta per vederla bene: servono le sue immagini, i fogli di stile, gli script. Con -r vengono già scaricati, tranne alla profondità massima, dove scrap si ferma. Con --page-requisites le risorse delle pagine vengono scaricate sempre, anche all'ultimo livello e anche fuori da --no-parent. Senza -r, salva una singola pagina completa:

$ scrap --page-requisites --convert-links https://esempio.it/articolo.html

Le regole del sito

Molti siti hanno un file robots.txt che chiede ai programmi automatici di non visitare certe parti. Quando copia un sito, scrap lo legge e lo rispetta: gli indirizzi vietati vengono saltati (con -v lo vedi scritto: bloccato da robots.txt). --robots=false ignora queste regole: usalo solo su siti tuoi o quando hai il permesso. Per i singoli file scaricati senza -r, robots.txt non viene consultato.

Filtri

Scegliere esattamente cosa scaricare: il cuore del coltellino.

Per tipo di file

$ scrap -r -A jpg,png,pdf https://esempio.it/

-A tiene solo i file con quelle estensioni; -R scarta quelle indicate (per esempio -R zip,exe). Maiuscole e minuscole sono uguali, il punto davanti è facoltativo.

Durante la copia di un sito, le pagine web vengono comunque lette per trovarne i link, ma vengono salvate solo se passano i filtri. Con -A jpg,png, quindi, scrap attraversa tutte le pagine ma sul disco trovi solo le immagini. Per tenere anche le pagine, aggiungi html alla lista (le pagine senza estensione, come /manuali/, contano come html).

Per nome o indirizzo

--accept-re segue solo gli indirizzi che contengono un certo schema, --reject-re esclude quelli che lo contengono. Lo schema è un'espressione regolare, un modo compatto di descrivere del testo:

ScriviVuol dire
--reject-re '/tag/|/autore/'salta gli indirizzi che contengono /tag/ o /autore/
--accept-re '2024'solo gli indirizzi che contengono 2024
--reject-re '\?'salta gli indirizzi con un ? (spesso ordinamenti e filtri del sito)

Scrivi lo schema tra apici singoli, come negli esempi, perché il terminale non ne cambi i simboli.

Attenzione

Questi due filtri valgono per ogni indirizzo, anche per le pagine da attraversare e per quello di partenza: con --accept-re 'pdf$' scrap scarta subito la pagina iniziale e non scarica niente. Per tenere solo certi file senza bloccare la navigazione usa -A pdf; --accept-re serve a restringere il giro, per esempio --accept-re '/manuali/'.

Per dimensione

--min-size 100k salta i file più piccoli di 100 kilobyte (utile per scartare miniature e icone), --max-size 50M quelli più grandi di 50 megabyte. La dimensione viene controllata prima di scaricare; se il server non la dichiara, il file viene scaricato.

Per contenuto

Il server dichiara che cosa sta mandando (il tipo di contenuto): image/jpeg, application/pdf, text/html… --types tiene solo i tipi indicati; con /* alla fine prendi un'intera famiglia:

$ scrap -r --types 'image/*,application/pdf' https://esempio.it/

È più affidabile di -A quando gli indirizzi non hanno estensione (per esempio /scarica?id=42).

Quanto in tutto

  • --max-files 200: si ferma dopo aver salvato 200 file (le pagine web salvate contano).
  • --quota 2G: si ferma dopo aver scaricato 2 gigabyte in tutto. I download già partiti possono superare un po' il limite; un file interrotto dalla quota resta .part.

Esempi

PerComando
Tutti i PDF di un sitoscrap -m -A pdf https://esempio.it/
Le foto, niente miniature, al massimo 500scrap -r -A jpg,jpeg,png --min-size 50k --max-files 500 https://esempio.it/galleria/
Un sito senza pagine di tag e ricerchescrap -m --reject-re '/tag/|\?s=' --convert-links https://esempio.it/
Solo una sezione, con le sue immaginiscrap -r --no-parent --page-requisites https://esempio.it/manuali/

Siti con accesso riservato

Scaricare da siti che chiedono utente e password, un login o un token.

Utente e password del server

Alcuni siti chiedono utente e password in una finestrella del browser, prima ancora di mostrare la pagina. Per questi:

$ scrap --user mario --password 'segreta' https://esempio.it/riservato/file.zip

scrap riconosce da solo i due sistemi usati (Basic e Digest). --auth digest evita di mandare la password in forma leggibile finché il server non la chiede in modo Digest.

Login da un modulo web

Molti siti hanno una pagina di login con un modulo. scrap può inviarlo prima di iniziare e poi usare la sessione ottenuta:

$ scrap --login-url https://esempio.it/login --login-data 'utente=mario&password=segreta' \
        --save-cookies sessione.txt -m https://esempio.it/area-soci/

In --login-data vanno i nomi dei campi del modulo, che trovi nel codice della pagina di login (nel browser: tasto destro sul campo, «Ispeziona», attributo name). Con --save-cookies la sessione viene salvata in un file; la volta dopo basta caricarla, senza rifare il login:

$ scrap --load-cookies sessione.txt https://esempio.it/area-soci/altro.pdf

Il formato è quello standard cookies.txt: puoi anche esportare i cookie dal browser con un'estensione e caricarli con --load-cookies. È il modo più sicuro per i siti con un login complicato (captcha, codici via SMS): entri nel browser, esporti i cookie, scarichi con scrap.

Limite

Il login da modulo invia soltanto i campi che scrivi. Se la pagina di login contiene un codice nascosto che cambia a ogni visita (molti siti lo fanno per sicurezza), il login fallisce: usa i cookie esportati dal browser.

Token, intestazioni e cookie a mano

  • --bearer TOKEN: per i servizi che danno un token di accesso (tipico delle API).
  • -H 'Nome: valore': aggiunge un'intestazione qualunque alla richiesta; si può ripetere.
  • --cookie 'nome=valore; altro=valore': manda dei cookie scritti a mano.
  • --referer e -U: dicono al server da quale pagina arrivi e con quale programma ti presenti (vedi il riferimento).
Attenzione alle password

Password e token scritti nel comando restano nella cronologia del terminale e, mentre scrap lavora, sono visibili agli altri utenti dello stesso computer. I file dei cookie (sessione.txt) valgono come una password: chi li ha entra nel sito al posto tuo. Non condividerli e non caricarli su GitHub (il repository di scrap ignora i nomi cookies.txt, cj.txt e *.cookies).

Problemi e soluzioni

Ogni messaggio di errore, cosa vuol dire e cosa fare.

Il programma si ferma subito

Questi messaggi fermano il programma prima di cominciare, con stato di uscita 2 (1 per il login).

Altre situazioni

La copia del sito non scarica quasi niente
Rilancia con -v e guarda il perché. Le cause più comuni: robots.txt vieta il sito; il sito costruisce le pagine con JavaScript; i link portano a un altro indirizzo (per esempio da esempio.it a esempio.com: aggiungilo con --domains); un filtro --accept-re blocca anche le pagine.
Il riepilogo dice «0 file» ma i file ci sono
I file erano già completi da un giro precedente e sono stati saltati: il riepilogo li conta come già presenti.
I download sono lenti
Controlla di non aver dato --rate. Prova più connessioni per file (-s 8) e più file insieme (-j).
Non vedo le barre, solo righe di testo
Succede quando l'uscita non va su un terminale (per esempio se la mandi in un file): è voluto. Le barre visibili insieme sono al massimo 6; gli altri file in corso sono riassunti in …e altri N in corso.
Lo uso in uno script
Controlla lo stato di uscita: 0 se è andato tutto bene, 1 se almeno un indirizzo è fallito, 2 per un'opzione sbagliata. -qa toglie tutti i messaggi.

Ripartire da zero

  1. Scarica il progetto: 
    $ git clone https://github.com/nic-fio/SCRAPER.git
$ cd SCRAPER
  2. Prova il programma: ./scrap --help. Fatto: il programma è già nel repository.
  3. Se vuoi, rendilo disponibile ovunque: sudo install -m 0755 scrap /usr/local/bin/scrap.

Se vuoi anche poter modificare e ricostruire scrap, prepara la macchina (installa Go e il resto, chiede sudo) e controlla che tutto funzioni:

$ tools/setup-dev.sh --install
$ make
$ make test

Un backup che non dipende da GitHub

tools/backup.sh salva l'intero progetto, con tutta la storia, in un solo file che si ripristina anche senza rete:

$ tools/backup.sh /media/chiavetta
$ git clone /media/chiavetta/scrap-2026-09-24.bundle SCRAPER

Riferimento delle opzioni

Tutte le opzioni, con il valore usato se non le indichi. Si possono scrivere con uno o due trattini: -mirror e --mirror sono la stessa cosa. Le opzioni vanno scritte prima degli indirizzi.

Download

-s, --split N
Connessioni (pezzi) per ogni file. Normale: 4. Vedi Connessioni per file.
-j, --jobs N
File (e pagine) lavorati insieme. Normale: 4.
--min-split SIZE
Sotto questa dimensione un file si scarica con una sola connessione. Normale: 1M.
-o, --output FILE
Nome (e percorso) del file da salvare. Solo con un indirizzo e senza -r/-m.
-d, --dir DIR
Cartella in cui salvare (creata se non c'è). Normale: la cartella corrente.
-c, --continue
Riprende i file rimasti a metà (.part). I file completi vengono saltati sempre. Vedi Interruzioni e ripresa.
--retries N
Nuovi tentativi dopo il primo, per ogni file o pezzo. Normale: 5. I rifiuti definitivi (401, 403, 404…) non si ritentano.
--retry-wait SEC
Attesa prima del primo nuovo tentativo; poi raddoppia a ogni tentativo, fino a 60 secondi. Normale: 2.
--rate SIZE
Limite di banda complessivo, al secondo, per esempio 2M. Normale: 0, nessun limite.
--timeout SEC
Attesa massima quando il server non risponde o smette di mandare dati. Non limita la durata di un download. Normale: 60; 0 toglie il limite.

Copia dei siti

-r, --recursive
Segue i link delle pagine e ricostruisce le cartelle del sito.
-l, --level N
Profondità massima: quanti passaggi di link dalla pagina iniziale. inf = senza limite. Normale: 5.
-m, --mirror
Copia completa: come -r -l inf.
--no-parent
Non risale sopra la cartella dell'indirizzo di partenza (il primo, se sono più d'uno).
--span-hosts
Segue anche i link verso altri siti. Da usare con un filtro.
--page-requisites
Scarica sempre le risorse delle pagine (immagini, stili, script), anche all'ultimo livello. Senza -r: una sola pagina completa. Vedi Le pagine complete.
--convert-links
Alla fine riscrive i link delle pagine salvate verso i file sul disco, per navigare senza rete.
--robots=false
Ignora robots.txt. Normale: le regole del sito vengono rispettate.

Filtri

-A, --accept LISTA
Estensioni da tenere, separate da virgola: jpg,png,pdf.
-R, --reject LISTA
Estensioni da scartare.
--accept-re REGEX
Solo gli indirizzi che corrispondono all'espressione regolare (pagine comprese).
--reject-re REGEX
Scarta gli indirizzi che corrispondono all'espressione regolare.
--domains LISTA
Solo questi siti (e i loro sottodomini). Sostituisce il limite normale al sito di partenza.
--exclude-domains LISTA
Mai questi siti.
--min-size SIZE
Salta i file più piccoli.
--max-size SIZE
Salta i file più grandi.
--types LISTA
Tipi di contenuto da tenere, per esempio image/*,application/pdf.
--max-files N
Si ferma dopo aver salvato N file. Normale: 0, nessun limite.
--quota SIZE
Si ferma dopo aver scaricato SIZE in tutto. Normale: 0, nessun limite.

Accesso e cookie

--user UTENTE
Nome utente per l'accesso del server (Basic o Digest).
--password PASS
Password per l'accesso del server.
--auth MODO
auto (normale) o basic: manda subito utente e password, e passa a Digest se il server lo chiede. digest: li manda solo quando il server li chiede in modo Digest.
--login-url URL
Indirizzo a cui inviare il modulo di login prima di iniziare.
--login-data DATI
Campi del modulo di login: utente=mario&password=segreta.
--bearer TOKEN
Token di accesso, mandato come Authorization: Bearer TOKEN.
-H, --header 'Nome: valore'
Intestazione aggiuntiva per ogni richiesta; si può ripetere.
--cookie 'k=v; …'
Cookie scritti a mano, mandati a ogni richiesta.
--load-cookies FILE
Carica i cookie da un file cookies.txt (formato Netscape, quello dei browser).
--save-cookies FILE
Alla fine salva i cookie in un file cookies.txt.

Generali

-U, --user-agent UA
Come scrap si presenta ai siti. Normale: scrap/1.1 (+https://github.com/nic-fio/SCRAPER), un nome onesto e riconoscibile. Da cambiare solo se un sito rifiuta i programmi.
--referer URL
La pagina da cui dici di arrivare; alcuni siti la controllano prima di dare un file.
--insecure
Non controlla i certificati di sicurezza dei siti https. Toglie una protezione: usala solo se sai perché.
-qe
Mostra solo gli errori.
-qa
Non mostra niente, errori compresi. Lo stato di uscita resta quello vero. Solo un'opzione sconosciuta al programma viene segnalata comunque.
-v, --verbose
Spiega ogni scelta: file saltati e perché, nuovi tentativi, login.
-i, --input-file FILE
Legge gli indirizzi da un file, uno per riga. Vedi Scaricare una lista.

Stati di uscita

StatoQuando
0Tutto scaricato. I file già presenti, saltati, contano come riusciti; anche i file esclusi dai filtri o da robots.txt.
1Almeno un indirizzo non è stato scaricato (il riepilogo dice quanti), oppure il login da modulo è fallito, o non è stato possibile salvare i cookie.
2Opzione sconosciuta o con un valore sbagliato.

Glossario

Crawl, copia di un sito
Visitare un sito seguendo i link da una pagina all'altra, come farebbe una persona, ma in automatico.
Profondità
Quanti link bisogna seguire dalla pagina iniziale per arrivare a una pagina.
Pezzo (segmento)
Una parte di un file scaricata con una connessione propria, insieme alle altre.
Estensione
La parte finale del nome di un file dopo il punto: jpg, pdf, zip.
Espressione regolare
Un modo compatto di descrivere del testo: a|b vuol dire «a oppure b», $ la fine, . un carattere qualunque.
Cookie
Un piccolo dato che il sito lascia al browser per riconoscerlo alle visite successive, per esempio dopo il login.
robots.txt
File di un sito con le regole per i programmi automatici: quali parti non visitare.
Certificato
Il documento digitale con cui un sito https dimostra la propria identità.
Release
Una versione pubblicata del programma, con i file pronti da scaricare.
